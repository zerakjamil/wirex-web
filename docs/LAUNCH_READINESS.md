Update 2026-10-17, Wireless LAN controller: the device library gained a wireless LAN controller (`WLC-PT`, UI label "Wireless LAN Controller") and a lightweight access point model (`LAP-PT`, `config.apMode: 'lightweight'`), with central switching as the operating model. `src/simulator/capwap.ts` implements the control plane: discovery (~2 s cadence) → Discovery Response → Join → fingerprint-driven Config Update (`configSeq`, ack, sequence-mismatch drops) → Run, with echo keepalives (~5 s) and a ~15 s AP timeout, and both sides self-heal across an outage.
