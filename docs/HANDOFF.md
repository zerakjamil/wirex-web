## Back stepping and event filters, 2026-10-17

## Wireless LAN controller (WLC), 2026-10-17

The completeness order's wireless item landed: a wireless LAN controller with lightweight access points and central switching. `src/types/network.ts` gained `DeviceType 'wlc'` (internal model `WLC-PT`, UI label "Wireless LAN Controller"), the `LAP-PT` lightweight AP model, `config.apMode: 'autonomous' | 'lightweight'` as the source of truth for AP behavior, and the `WlanProfile`/`ApRuntime`/`WlcRuntime` shapes (runtime state is volatile and tolerantly absent after reload). The controller carries two gigabitethernet ports with the management IP on `ports[0]`, so ARP/ICMP for the controller reuse the normal host paths. `src/simulator/capwap.ts` is the control plane: discovery broadcast (~2 s cadence) → Discovery Response → Join → fingerprint-driven Config Update (`configSeq` bumps on WLAN changes, sequence mismatch drops, APs apply and acknowledge) → Run, with echo keepalives (~5 s) and a ~15 s AP timeout; both sides self-heal, so losing and restoring the controller path re-enters Run without manual steps. CAPWAP is modeled at layer 2 (custom ethertype `0x88B5`) on the wired broadcast domain, so lightweight APs need no IP of their own. ## EIGRP (IPv4), 2026-10-17

The completeness order's first post-IPv6 item landed: EIGRP. `src/simulator/eigrp.ts` implements Hello/Hold adjacencies (5 s Hello / 15 s Hold to `224.0.0.10` / `01:00:5e:00:00:0a`, ethertype `0x0800` with a structured `EIGRP` protocol label), unicast full-table updates to newly discovered neighbors, signature-driven triggered multicast updates on topology change, and candidate withdrawal on hold expiry, port shutdown, or `complete` updates that no longer advertise a prefix. Metrics follow the IOS classic composite formula `256 × (10^7/min bandwidth + cumulative delay/10)` with GigabitEthernet 1,000,000 kbps/10 µs, FastEthernet 100,000 kbps/100 µs and Serial 1,544 kbps/20,000 µs defaults; the three-Gigabit campus fixture learns 3072 (one router) and 3328 (two routers). Learned routes install as distance-90 `D` entries with lowest-metric successor selection and a deterministic next-hop tie break, never over connected subnets, with split horizon per egress interface. CLI: `router eigrp <1-65535>` (`network <IPv4> [wildcard]`, classful wildcard default, `no network`, `auto-summary`/`no auto-summary`, `passive-interface`/`default`/`no passive-interface`, `eigrp router-id`, `no router eigrp`), `show ip eigrp neighbors`/`topology`/`interfaces`, `show ip protocols` section, `show ip route` `D` lines with `[90/<metric>]`, running-config block, and PKT/workspace config round-trip through the standard `newDeviceConfig` path. Verification: `npx tsc --noEmit` clean; `npm test` passes 458/458 (5 new packet-level tests — three-router convergence with learned metrics and CLI assertions; a routed PC-to-PC echo reply; AS mismatch blocks the adjacency, leaves `lastError` and fails the ping cleanly; link shutdown withdraws the route and `no router eigrp` flushes runtime and routes; EIGRP over GRE learns the remote LAN via Tunnel0 and returns a routed echo); lint zero errors/28 warnings; `npm run check` green (build + zero-vulnerability audit); the production-browser suite passes 34/34 including new F11 (EIGRP process/network CLI shows in `show ip protocols`, `show ip eigrp topology` and running-config) and the realtime scale flow on this run (longest task 247 ms against the 500 ms bound; p95 tick 87.9 ms; simulator tick 9.2 ms p95). ## IPv6 OSPFv3 (slice 5), 2026-10-17

Enablement is per interface (`ipv6 ospf <1-65535> area <0-4294967295>` plus `ipv6 ospf cost` / `ipv6 ospf priority`) and per device (`ipv6 router ospf <1-65535>` entering a `config-rtr` mode with `router-id`); one process per device, numeric areas only. `show ipv6 ospf`, `show ipv6 ospf neighbor` (states, DR/BDR roles, dead timers, last rejected packet reasons), `show ipv6 ospf database` and `show ipv6 ospf interface` render the runtime; `show ipv6 route` surfaces learned `O` entries and running-config prints the mode block and interface lines.
